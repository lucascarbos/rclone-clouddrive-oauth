Uso pessoal

rclone CloudDrive

O rclone CloudDrive é uma configuração pessoal de armazenamento executada em um computador Windows. Ela usa o software rclone para apresentar contas do Google Drive autorizadas pelo proprietário como uma unidade local.

Finalidade

O acesso ao Google Drive é utilizado somente para listar, ler, criar, atualizar e excluir arquivos conforme as operações feitas pelo próprio proprietário no computador. O aplicativo não é oferecido como serviço ao público e não possui cadastro de usuários.

Como os dados são tratados

  • Os arquivos permanecem nas contas do Google Drive autorizadas.
  • O processamento e o cache necessários ao funcionamento são realizados localmente no computador do proprietário.
  • Não há servidor externo do aplicativo, publicidade, venda de dados ou compartilhamento com terceiros.
